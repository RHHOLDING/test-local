# HANTECH — AC shop design preview

Static design preview of the new HANTECH storefront (Magento theme `Hantech/ac`), exported for client review.

- `/` — homepage with scroll-driven AC airflow hero
- `/split-air-conditioners.html` etc. — category pages
- `/hantech-black-edition-split-3-5-kw.html` — product page with installation package
- `/installer/register/` — installer registration wizard
- `/installer/login/` — partner login
- `/installer/portal/` — partner portal preview

Design only: cart, checkout, search and account actions are disabled. Pages are marked `noindex`.

## Vercel
Import this repo in Vercel → Framework preset **Other**, no build command, output directory `./` (root).
